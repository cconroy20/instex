# Interferometer: Deep Synoptic Array (DSA, formerly DSA-2000) -- FDR-baseline configuration (1650 x 6.155 m), site, band, primary beam, tracking, synthesized beam

Compiled 2026-10-20 for the instex INTERFEROMETER mode, in the record format of `data/interf/vla.md`. Every number comes from a document saved unmodified under `rawdata/interf/dsa/`; each value carries its source key, location and a short verbatim quote. **DERIVED** marks arithmetic done here (shown). **INFERRED** marks a mapping no source states. **NOT FOUND** marks a gap. Downloaded files were read as text only (pdftotext for PDFs; tag-stripped text for HTML; JSON and cfg as data); nothing downloaded was run. Companion machine-readable file: `data/interf/dsa2000.json`. Machine check: see the last section.

## Completeness summary

**Antenna positions (1650)**: the project's own sensitivity calculator loads `antennas_enu.json` (ENU), configuration "dsa1650_P305_v2.5.6.8", which the calculator documents as the project baseline at the Final Design Review (ETC). Positions are local east, north, up in metres "relative to array centroid", 0.1 m resolution; copied without conversion (the mean of each axis is zero to 1 mm, DERIVED). Names are file-order indices (INFERRED).

**Baselines (DERIVED)**: 1,360,425 pairs; Bmin 10.20 m, Bmax 20299.14 m vs ETC "1,360,425 baselines from 10.2 m to 20.3 km" (agree). Footprint 16.4 km E-W x 20.1 km N-S vs "20 km x 16 km" (OVW).

**Site**: Spring Valley, Nevada; lat 39.55393, lon -114.42415, height 1746.3 m (ENU header; height datum NOT FOUND). **Dish** 6.155 m (ETC; 6.15 m on OVW). **Band** 0.70-2.00 GHz, dual linear, covered instantaneously (1.30 GHz). **Primary beam** Gaussian FWHM 3.36 deg/nu_GHz (ETC). **Tracking**: fully steerable az-el dishes; the calculator models targeted tracks as |HA| <= 2 h about transit above 20 deg elevation; survey pointings 21 min. **Synthesized beam** natural 3.03" x 2.31" PA 90.6 deg at zenith, 1.35 GHz (ETC); uniform 2.03" x 1.57" (PSF).

**Scope**: current design only. The superseded 2000 x 5 m design (2019 white paper and the whitepaper-era cfg files) appears as ALT values and as DERIVED statistics under "Historical configurations".
