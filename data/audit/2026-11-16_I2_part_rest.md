## Cross-cutting finding (hsc, decam, megacam): F1 is ignored, the primary is drawn at f/F

imager.js design(): the prime-focus branch that honors F1 requires `P.corrector` (`P.tel === "prime" && P.corrector && P.F1 && ...`). The three presets set F1 but no corrector, so the final `else` branch runs with `f1 = P.F * Dmm`. Measured with IM.design:

| preset | F1 in preset | primary focal length drawn | real primary focal length (source) |
|---|---|---|---|
| hsc | 1.83 | 18.45 m (f/2.25) | 15 m, f/1.83 (Subaru "Focal length: 15 m", STP) |
| decam | 2.7 | 11.72 m | 10.656 m, f/2.7 (F15 Sec. 2.1.1; BOP R = 21311.6 mm) |
| megacam | 3.77 | 14.89 m | 13.533 m (COM4 "naked prime focus ... 13533 mm") |

The Telescopes mode already carries the fix for the same telescopes: web/tpresets.js lines 189 (Subaru: `corrector: { d: 1.0, ...}`) and 288 (Blanco: `corrector: { d: 1.237, ...}`). Effect: layout labels and the drawn focus position are wrong; pixel scale, field, étendue, PSF are unchanged (they depend only on F). Fix: add a corrector entry to each (MegaPrime has none in tpresets; its distance would be a schematic choice and must be flagged). lsst uses `tel: "pb"` (honors F1) and is not affected. (LBC has the same gap; see the VST/LBC part.)

## lsst (Rubin / LSSTCam)

1. Values verified (via the record, quotes in widefield.md): D 8.36 m and inner 5.12 m (ROD para. 4), F 1.233 (RKN "Final f-ratio: f/1.233"), 189 CCDs, rows 9/9/9/15x9/9/9/9, 10 µm, 42.25 mm pitch, 127 mm raft pitch (OBSL). Model: 0.2001 "/px, 189/189 chips whole, 634 mm mosaic.
2. Error (scoring text, low): the pub line "field 9.6 deg²" carries `src: "Ivezić+19 (the CCDs' area)"`. The published 9.6 deg² is the area of the 3.5 deg circle (RKN "Field of View (FOV): 3.5 deg (9.6 deg 2)"; pi x 1.75^2 = 9.62). The CCD active area is 9.55 deg² (DERIVED, widefield.md). The model's 9.569 (-0.32%) matches both by coincidence of design; the check passes at 1% tol but the label misattributes. Fix the src text. With the published 3.5 deg circle (field: 210) the model gives 8.59 deg² (corner CCDs cut), so the note's "field circle takes in the whole focal plane" is the explicit choice.
3. Misleading: note says "the published 9.6 deg² is the area of the CCDs"; this is not what the source says (above).
4. étendue (info): model 328.5 vs 319 (+3.0%). The 319 includes vignetting (SB09 Sec. 2.3 "including the effects of camera vignetting"; RKN mean effective aperture 6.49 m). The scored info line says "area and field definitions are not given"; the vignetting statement is in the record and should replace it.
5. npix: scored value 3,091,504,128 in validate (record DERIVED 3,091,580,928; the preset's value is 76,800 lower, i.e. a different arithmetic: 117x4096x4004 + 72x4072x4000 = 1,918,... check: 117 x 16,400,384 = 1,918,844,928; 72 x 16,288,000 = 1,172,736,000; sum 3,091,580,928). The preset value 3,091,504,128 is off by 76,800 (0.0025%); harmless but wrong. Model 3.0997e9 is +0.26% because one format is used; the tolerance 0.6% hides that the model overcounts by 8.1 Mpix. Fix the value to 3,091,580,928.
6. DERIVED/INFERRED: eps 0.612 is the M1 inner clear edge (ROD, BAT agree: 5.12/8.36). The camera, spiders (eight 50 mm vanes, imSim) and M2 are not in eps; collecting area 34.33 m² is on-axis, unvignetted. M1 f/1.19 DERIVED from the third-party batoid R = 19.835 m. Gaps are nominal (LCA-13381 not public); ITL rafts have wider in-raft gaps (1.53/2.25 mm) than e2v; the preset uses e2v + "mixed" for all rafts: stated in the note.
7. Layout (disclosed only in tpresets.js): the Paul-Baker drawing puts the focal plane 5.23 m above M1 vertex vs the real 4.43 m and M3 0.17 m in front vs the real 0.23 m behind. The imager note does not say so.
8. Scored checks: pixScale 0.2 (RKN "Pixel scale: 0.2 arcsec/pixel"): F derived from the OBSL plate scale, so not independent (scored, not marked circular; mark info). Others fine.

## hsc (Subaru / Hyper Suprime-Cam)

1. Verified from the record: D 8.2 (STP "Effective diameter: 8.2 m"), 104 science CCDs 2048 x 4176 (OBSS bbox; SHP/A18 say 2048 x 4096), 15 µm, rows 7/13/15/15/15/15/13/7 + 4 rotated, gaps 1.12 / 4.51 / 1.13 mm (DERIVED from OBSS; published "approximately 12 arcsec and 53 arcsec", derived 12.6 and 50.5), field 1.5 deg, 26% vignetting at 0.75 deg (A18 Sec. 2).
2. Error (see cross-cutting): primary drawn f/2.25, 18.45 m, instead of f/1.83, 15 m.
3. Unsupported / not settled: eps = 0 is a placeholder, NOT FOUND (Miyazaki+18 PASJ 70 S1 not obtainable; OUP 403 in the record; one more search by me found no usable text). Effect: collecting area drawn 52.81 m² (pi/4 x 8.2^2) is an upper bound; with the WFC barrel only (0.97 m, 0.118) it would be 52.0 m². The Telescopes mode uses eps 0.289 for the Subaru group, but that comes from the IR Nasmyth pupil (SCExAO), not prime focus, so it cannot be transferred. Open question for the builders.
4. Not modeled and not in the note: in rows 3-6 the three outermost columns on one side belong to the other half and sit 3.4 mm higher (widefield.md chip_gaps); the preset draws centered rows with one gap list. The note says "two halves ... gap narrower" only.
5. Pixel scale: F = 2.25 derived from the pipeline default plateScale 11.2"/mm (OBSS), A18 "15 µm ≃ 0.168"" (rounded; HSC pages say 0.17"). F = 2.2 would give 0.1715" (+2.1%). Disclosed.
6. Scored/info: all three pub lines info. The 1.77 deg² is A18's area inside 49 arcmin masking, vs model 1.930 (+9%) because the 104 CCDs reach to 0.90 deg radius. Note says this. With a 90' circle the model gives 1.60 deg² and 738 Mpix, so there is no configuration in which the model reproduces 1.77; the "1.5 deg field" is only text.
7. Note sentence "unvignetted to 10′" follows A18 text but A18 Table 1 says "0 at 0.15°" (conflict listed in the record, not in the note).

## decam (Blanco / DECam)

1. Verified from the record: D 3.934 (BOP "Used clear aperture diam 3934 mm"), 62 CCDs 2048 x 4096, 15 µm, rows 3/4/5/6/6/7/7/6/6/5/4/3, gaps 2.3 mm (short edge, along row) and 3.0 mm (long edge) (CDC; NDH Table 4-1; OBSD 2.30/3.02), centre in the S4/N4 gap (NDH Sec. 4.1.1), F = 2.98 (F15 f/3.0; 17.575"/mm OBSD) -> 0.2639" vs 0.2637 published centre (+0.08%).
2. Error (see cross-cutting): primary drawn f/2.98 (11.72 m) instead of f/2.7 (10.656 m).
3. Inconsistency (medium): eps = 0.42 (1651 mm "PF cage baffle for f/8 M2", pre-DECam, BOP) gives 10.01 m². The Telescopes-mode Blanco entry (same telescope, same page) draws the post-DECam pupil (1.65 m cage shadow, filter-changer housing, four fins) and reports 9.31 m² DERIVED. The Imager and Telescopes modes disagree by 7% on collecting area for the same instrument. The note discloses the source of 0.42, but not the Telescopes-mode value.
4. Scored check: "field 3 deg²" passes at tol 10% (model 2.795, -6.85%). The source is a rounded "3 square degree (2.2 degree field of view)" (CDC); the model number is the active-pixel area (DERIVED 2.79 in the record). A 10% tolerance on a one-significant-figure value makes the check nearly uninformative; the published 3 deg² is probably the 2.2 deg circle's area class (3.80 deg² is the circle, DERIVED), neither reproduces it. State this.
5. Silent: two dead/partial CCDs (N30 not functional; S30 not functional 2014-2016; NDM "60.5 useful") not mentioned; the 520 Mpix check counts all 62.

## megacam (CFHT / MegaCam)

1. Verified from the record (CGI, CID, CRD, CTC, quotes in megacam_ztf_small.md): 40 CCDs 2048 x 4612, 13.5 µm; rows 9/11/11/9 ("first and last rows have 9 CCDs, middle rows have 11"); gaps ~13" (70 px = 0.945 mm) and ~80" (425 px = 5.74 mm); the two middle rows separated by a small gap (CTC "three large stripes ... one arcminute gap"); D = 3.58 (COM4 "usable diameter of 3.58 m"); 378 Mpix.
2. eps 0.451: arithmetic reproduces CFHT's 80,216 cm² (model collecting area 8.02 m²). Supported (CTC Sec. 2.3).
3. Error (see cross-cutting): primary drawn at 14.89 m, f/4.16; real 13.533 m.
4. F = 4.16 from 0.187" (CGI, centre of field) vs 0.185" in CID, the FITS header (PIXSCAL1 = 0.1850) and R09: F would be 4.20 (+1.1% in scale). The note says "F comes from the published 0.187"/px" without noting the 0.185 alternative.
5. Field circle 90' and fields: "0.96 x 0.94 deg (36 CCDs)" info line compares model fieldY 60.4' with 56.4' (+7%). The layout itself gives 1.006 deg N-S for any chip count (record, DETSIZE frame 1.206 x 1.005 deg). The published number likely excludes something (gaps/overlap); the info line does not explain. Corrected-field diameter NOT published; the 90' circle is arbitrary (the mosaic circumscribes to 1.41 deg; the model draws all 40). The note does not say the circle is arbitrary.
6. Not stated in the note: before 2015A only the central 36 CCDs were read out; the old filters vignette the ears.

## ztf (Palomar 48-inch / ZTF)

1. Verified from the record (D20 Table 1, B19 Table 1): entrance pupil 1244.6 mm, working focal ratio 2.46, 16 CCDs 6144 x 6160, 15 µm, 22.4% obscuration on axis (B19 Sec. 2.2) -> eps 0.473 (sqrt 0.224; the model's collecting area 0.94 m² matches the 22.4%), 47.7 deg² (B19), 605.6 Mpix.
2. Conflict hidden by the note (medium): gaps 7.49 x 10.96 mm are DERIVED from the on-sky gaps 0.140 / 0.205 deg (B19 Table 1 "Chip gaps 0.205 N-S, 0.140 E-W"), but the physical mosaic size in the camera papers (386 x 395 mm) implies 5.79 / 8.47 mm. Model with the current gaps: 391.1 x 402.5 mm mosaic, 7.309 x 7.521 deg (published 7.32 x 7.50). With 5.79 / 8.47 mm: 47.52 deg², 7.214 x 7.382 deg, 1.4% and 1.6% below the published field. The record lists the conflict; the preset note says only "the gaps are those that reproduce the published on-sky gaps". Both candidate gaps produce a pixel scale of 1.0105"/px. Say that the physical value differs.
3. Scored: "field 7.32 deg E-W" is info (circular: gaps derived from the same paper), area 47.7 passes at 1% (-0.40%), pixel scale passes (F and D from Dekany+20; independent of the pixel size, so a real check: 15 µm, f = 3.062 m gives 1.0105").
4. Plate scale in the Telescopes mode: 67.33"/mm; Imager model: 67.37"/mm (+0.05%), from D x F rounded at 2.46. Immaterial.
5. The default seeing (0.8") gives 0.80 px per FWHM and a permanent "undersampled" flag; true to the instrument (1.01"/px; typical ZTF seeing 2") but the default can mislead.
6. 4 guide/focus CCDs (2048 x 2048) outside the science rows are not drawn; the note does not mention them.

Image Circle ∅44mm"; ZWO "Pixel Size 3.76μm", "Sony IMX571 Sensor, measuring 23.5mm × 15.7mm with a 28.3mm diagonal", "Resolution 6248×4176". 478 x 206264.8^-1 scale 1.6228"/px, 26.09 Mpix. The note's "the makers publish no pixel scale or field": none of the three pages contains an arcsec value (grep). Supported.
2. Cosmetic: note and group say "80 mm", the data say 81 mm; the aperture entered is 0.081 (correct).

The assumed combination (a William Optics tube, a ZWO camera) is a typical-setup choice, labeled so. The "undersampled" flag at 0.8" seeing (1.11 px/FWHM) is real for this setup.

## Ranked summary

(a) Confirmed errors:
1. hsc, decam, megacam: F1 has no effect without a `corrector` entry, so the primary is drawn with the final focal length (HSC 18.45 m vs 15 m; DECam 11.72 vs 10.656 m; MegaCam 14.89 vs 13.533 m). Fix: corrector entries as in tpresets.js lines 189 and 288. Effect: layout/labels only (medium).
2. decam: eps 0.42 (pre-DECam f/8 value, area 10.01 m²) disagrees with the Telescopes-mode post-DECam pupil (9.31 m²). Fix: use the same pupil or state the choice (medium).
3. ztf: gap conflict (on-sky-derived 7.49/10.96 mm vs physical 5.79/8.47 mm) not shown in the note (medium; field changes 1.5%).
4. lsst: "9.6 deg² is the area of the CCDs" is wrong (circle area; CCD area 9.55); npix value 3,091,504,128 should be 3,091,580,928; étendue info line misses the vignetting explanation (low).
5. decam: the 3 deg² check at 10% tolerance is uninformative; megacam F alternative 0.185" (4.20) not noted (low).

(b) Unsupported or not settled: HSC eps = 0 (placeholder; collecting area an upper bound); HSC row-offset structure not modeled; MegaCam 90' and ZTF 720' field circles are arbitrary; LSST drawing disclosed only in tpresets.js.

(c) Open questions for the builders: HSC prime-focus central obscuration (Miyazaki+18); ZTF true chip gaps in mm; whether the Imager should use the Telescopes-mode Blanco pupil; whether a corrector entry should be added for MegaPrime (position schematic).

(d) New sources saved: none.
